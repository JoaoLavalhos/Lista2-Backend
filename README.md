# Lista de Exercícios — Backend

Repositório acadêmico com uma sequência de exercícios desenvolvidos durante as aulas de backend.

Os exercícios estão organizados em pastas individuais e registram a evolução prática dos conteúdos trabalhados na disciplina.

## Objetivo

Praticar fundamentos de desenvolvimento backend por meio de pequenos problemas independentes, com foco em lógica, organização do código e construção progressiva de aplicações.

## Organização

Cada pasta `ExercicioX` corresponde a uma atividade da lista proposta em aula.

> Este repositório é mantido como histórico acadêmico. Projetos completos e de portfólio estão destacados separadamente no perfil.
